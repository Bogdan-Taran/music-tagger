# MusicTagger

Редактор музыкальных тегов с русским графическим интерфейсом. Работает с MP3, FLAC, M4A (без DRM), OGG Vorbis и Opus. Аудио не перекодируется. Изменения записываются в копии, исходные файлы остаются на месте.

## Запуск на Windows

1. Установите Python 3.11 или новее с https://www.python.org/downloads/ (обычный установщик с Tcl/Tk; включите Add Python to PATH).
2. Распакуйте архив целиком в обычную папку.
3. Дважды нажмите `start_windows.bat`. При первом запуске нужен интернет для установки библиотек. Затем приложение работает локально.

Чтобы получить самостоятельный EXE: после первого запуска откройте `build_windows.bat`. Результат — `dist/MusicTagger.exe`; его можно перенести на другой Windows-ПК той же архитектуры без установки Python. Сборка выполняется на Windows. Готового EXE в этом архиве нет.

## Как пользоваться

1. Нажмите «Добавить песни» или «Добавить папку» (берутся файлы непосредственно из папки).
2. Выберите одну песню. Справа измените название, исполнителя, альбом, исполнителя альбома, дату, жанр, номер трека или комментарий. Поля сразу обновляют черновик этой песни. Переключайтесь между песнями и задавайте каждой собственное название.
3. Выделите несколько песен через Ctrl (Cmd на macOS) или Shift. Нажмите «Общие теги…» и отметьте только поля, которые хотите изменить. Отмеченное пустое поле удаляет тег; неотмеченные поля сохраняются.
4. Для общей обложки выделите песни и нажмите «Обложка для выделенных…». Картинка встраивается в каждую песню. JPEG, PNG и WebP приводятся к JPEG размером не более 1600 × 1600 с сохранением пропорций; прозрачность не сохраняется. «Удалить» удаляет все встроенные обложки у выделенных песен.
5. При необходимости нажмите «Названия из имён файлов». Это копирует имя файла без расширения в тег названия. Если в имени тоже кракозябры, введите название вручную: программа не угадывает исходный текст.
6. Выберите место сохранения, имя новой папки и шаблон имени файлов. Будущие имена видны в таблице (прокрутите её вправо).
7. Нажмите «Сохранить копии». Сохраняются **все песни из списка**, а не только выделенные.

Шаблоны: название; исполнитель — название; номер — название; исходное имя. При пустом названии для имени копии используется исходное имя файла. Запрещённые символы заменяются подчёркиванием. Совпадения получают суффикс `(2)`, `(3)` и т. д.; существующие файлы не перезаписываются. Если указанная папка уже есть, копии добавляются в неё.

Номер трека: `3` или `3/12`. Дата: `2026`, `2026-11` или `2026-11-01`. Пустое поле у одной песни удаляет соответствующий тег. Остальные теги сохраняются библиотекой Mutagen. Сброс возвращает черновик к тегам исходного файла. Удаление из списка не удаляет файл с диска.

При ошибке отдельного файла остальные продолжают сохраняться; сообщение показывает результат и ошибки. Повторный экспорт создаёт дополнительные копии. Черновики между запусками не сохраняются.

## Запуск на Mac

1. Установите Python 3.11 или новее: [macOS installer с python.org](https://www.python.org/downloads/macos/). В официальный установщик входит графическая библиотека Tk. Старый системный Python от Apple не подходит.
2. Распакуйте архив целиком, например в «Документы». Не переносите отдельный файл запуска без остальных файлов.
3. Дважды нажмите `start_macos.command`. При первом запуске библиотеки установятся автоматически — нужен интернет. Откроется окно MusicTagger и служебное окно Терминала. Пока работает приложение, оставьте это окно открытым.

Лаунчер самостоятельно ищет подходящий Python, в том числе при запуске из Finder, и использует отдельное окружение `.venv-macos`. Поддерживаются Mac с Apple Silicon и Intel при установке подходящего Python. Все функции редактора доступны и на Mac.

### Обычное приложение .app

Дважды нажмите `build_macos.command`. После установки библиотек и сборки Finder покажет `dist-macos/MusicTagger.app`. Перенесите **весь файл-приложение MusicTagger.app** в «Программы» и запускайте его как обычное приложение: Python и Терминал для его запуска уже не нужны.

Сборка создаётся на вашем Mac для архитектуры используемого Python; универсальность и работа на более старой macOS не гарантируются. Готовая сборка `.app` в исходный архив не включена. Приложение не имеет подписи Apple Developer и нотариализации. Если macOS ограничивает первый запуск доверенного вами файла, используйте штатное разрешение в «Системные настройки → Конфиденциальность и безопасность»; отключать защиту системы не нужно.

Если файл `.command` потерял разрешение на запуск при распаковке, откройте Терминал в папке MusicTagger и выполните:

```sh
chmod +x start_macos.command build_macos.command
./start_macos.command
```

Основа сборки: [PyInstaller — создание macOS app bundle](https://pyinstaller.org/en/stable/usage.html); [Python и Tk на macOS](https://www.python.org/download/mac/tcltk/).

## Linux

Нужен Python 3.9+ с Tkinter. В терминале, находясь в папке приложения:

```sh
python3 -m venv .venv
.venv/bin/python -m pip install -r requirements.txt
.venv/bin/python music_tagger.py
```

В Linux может понадобиться системный пакет `python3-tk`.

Техническая основа: [Mutagen](https://mutagen.readthedocs.io/en/latest/) для тегов, Tkinter для интерфейса, Pillow для обложек. WAV, WMA, защищённые M4A и Ogg FLAC не поддерживаются.
